# Мониторинг аккаунтов Brawl Stars и Clash Royale (FunPay + LolzMarket)

Бот раз в N минут проверяет объявления о продаже аккаунтов Brawl Stars и Clash Royale
на **FunPay** и **LolzMarket**. Если объявление подходит под ваши условия (цена, кубки,
бравлеры, уровень, слова в тексте, продавец), бот присылает в Telegram сообщение
с параметрами и кнопкой «Открыть объявление».

Когда приходит уведомление:

- 🆕 **Новое объявление** подходит под условия;
- 🔔 **Теперь подходит под условия** — объявление уже было на сайте, но раньше не подходило
  (подешевело, продавец дописал описание, вышел в онлайн и т.п.);
- 📉 **Цена снижена** — объявление, о котором уже сообщали, подешевело хотя бы на
  `min_price_drop_percent` процентов (по умолчанию 5%).

Об одном объявлении повторно бот не пишет. При первом запуске и после изменения условий
в `config.yaml` бот только запоминает уже висящие объявления, чтобы не прислать сразу сотню
старых (это меняется настройкой `notify_on_first_run`). Если сайт перестал отвечать (бан, защита,
смена вёрстки), после 3 неудачных проверок подряд бот предупредит в Telegram, а когда сайт снова
заработает — тоже напишет.

## 1. Что понадобится

1. **Python 3.10 или новее.** Windows: https://www.python.org/downloads/ (при установке отметьте «Add Python to PATH»).
2. **Telegram-бот:**
   - напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → получите **токен** вида `123456789:AAE...`;
   - откройте своего бота и нажмите **Start** (иначе бот не сможет вам писать);
   - узнайте свой **chat id**: напишите [@userinfobot](https://t.me/userinfobot), он ответит числом `Id`.
3. **Токен LolzMarket** (если нужен Lolz):
   - https://lolz.live/account/api (зеркала: lolz.team, zelenka.guru) → создать API-клиент → получить токен с правом **market**;
   - Market API доступен, если у вас **200+ симпатий** на форуме, или по **платной подписке**.
     Без доступа выключите Lolz в конфиге (`lolz: enabled: false`), FunPay будет работать и так.

## 2. Установка и запуск

**Windows** (в папке `market-parser`, командная строка или PowerShell):

```bat
py -m pip install -r requirements.txt
copy config.example.yaml config.yaml
```

**Linux / VPS (Ubuntu, Debian)** — через виртуальное окружение (на новых Ubuntu `pip` вне него не работает):

```bash
sudo apt install -y python3 python3-venv
cd market-parser
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config.example.yaml config.yaml
```

Откройте `config.yaml`, впишите токен бота, chat id, токен Lolz и свои условия. Затем
(на Linux вместо `py` пишите `.venv/bin/python`):

```bash
py main.py --test-telegram     # бот пришлёт тестовое сообщение (или объяснит, что не так)
py main.py --once --dry-run    # одна пробная проверка: уведомления печатаются в консоль
py main.py                     # рабочий режим, Ctrl+C — остановить
```

`--dry-run` ничего не запоминает, поэтому его можно запускать сколько угодно, подбирая условия.
Совет: поставьте на время `notify_on_first_run: true` и запустите `py main.py --once --dry-run` —
увидите, какие из текущих объявлений подходят под ваши условия.

## 3. Условия (раздел `rules`)

Правил может быть сколько угодно. Объявление присылается, если подходит **хотя бы под одно**.
Внутри правила должны выполняться **все** заданные условия. Ненужное условие просто удалите.

| Поле | Что значит |
|---|---|
| `name` | название правила (будет в уведомлении) |
| `game` | `brawl_stars` или `clash_royale` |
| `sites` | `[funpay, lolz]`, `[funpay]` или `[lolz]` |
| `price_min`, `price_max` | цена в рублях, включительно |
| `trophies_min`, `trophies_max` | кубки |
| `brawlers_min` | бравлеров не меньше (только Brawl Stars) |
| `level_min` | уровень (BS — уровень аккаунта, CR — уровень короля) |
| `include_all` | все эти слова должны встречаться в тексте объявления |
| `include_any` | хотя бы одно из этих слов |
| `exclude` | ни одного из этих слов |
| `allow_unknown` | FunPay: если кубки/бравлеры/уровень не удалось найти в тексте — `false` пропустить, `true` прислать |
| `online_only` | FunPay: продавец сейчас онлайн |
| `min_reviews` | FunPay: отзывов у продавца не меньше |
| `min_rating` | FunPay: рейтинг продавца не ниже (у продавцов меньше чем с 10 отзывами рейтинга нет — они не пройдут) |
| `lolz_params` | LolzMarket: любые параметры поиска API как есть |

**Как ищутся слова.** Без учёта регистра и с начала слова: `аренд` найдёт «аренда», «аренду», «аренды»,
а `rent` не сработает на «different». Поэтому лучше писать начало слова: `["аренд", "почт"]`.

**Где ищутся слова и числа:**
- **LolzMarket** — в названии и полном описании. Кубки, бравлеры и уровень LolzMarket отдаёт точными
  числами, а условия правила передаются прямо в поиск API — сайт сам отбирает подходящие объявления.
- **FunPay** — только в **коротком тексте объявления из списка** (полное описание бот не открывает,
  чтобы не делать сотни лишних запросов). Отдельных полей «кубки / бравлеры» FunPay не даёт, поэтому
  бот ищет числа в этом тексте: «35к кубков», «Кубков: 35 000», «70 бравлеров», «уровень короля 14»,
  «КБ 14». Если продавец их не написал, работает `allow_unknown`: при `false` такое объявление
  пропускается (меньше лишних уведомлений, но можно упустить хорошее), при `true` — присылается.

Пример `lolz_params` (полный список — в документации API, раздел Category Search → Supercell,
https://lzt-market.readme.io):

```yaml
    lolz_params:
      origin: [personal, resale]        # происхождение аккаунта
      legendary_brawlers_min: 5         # легендарных бравлеров
      hypercharges_min: 10              # гиперзарядов
      brawl_highest_trophies_min: 40000 # максимум кубков за всё время
      royale_evolved_min: 3             # эволюций (Clash Royale)
      tel: no                           # без привязанного телефона
      eg: 1                             # гарантия 3 дня
```

## 4. Как менять интервал

1. В `config.yaml`: `monitor: interval_minutes: 5` (нужен перезапуск).
2. В Telegram: `/interval 10` — сразу, без перезапуска; сохраняется и после перезапуска.
   `/interval reset` возвращает значение из `config.yaml`. Если после `/interval` поменять
   `interval_minutes` в `config.yaml` и перезапустить бота, снова будет действовать конфиг.
3. При запуске: `py main.py --interval 10` — только на этот запуск (не сохраняется).

Если заданы несколько способов, действует последний из них; `/status` и `/interval` показывают,
откуда взято текущее значение. Допустимо от 1 до 1440 минут. Рекомендуется не меньше 3–5 минут
(см. «Ограничения»).

## 5. Команды бота

| Команда | Действие |
|---|---|
| `/status` | состояние, время и результат последней проверки, ошибки сайтов |
| `/interval` | показать интервал; `/interval 10` — изменить; `/interval reset` — сбросить |
| `/check` | проверить прямо сейчас (работает и на паузе) |
| `/pause`, `/resume` | приостановить и продолжить; пауза сохраняется и после перезапуска |
| `/rules` | показать заданные условия |

Команды принимаются только из чатов, указанных в `telegram.chat_ids`.
Если за одну проверку нашлось больше `max_notifications_per_cycle` объявлений, остальные придут
одним сообщением-списком со ссылками.

## 6. Ограничения сайтов

Коротко: бот делает за одну проверку 1 запрос к FunPay на каждую игру и 1 запрос к LolzMarket
на каждое правило. При интервале 5 минут это меньше одного запроса в минуту на сайт, то есть
намного ниже любых лимитов. Между запросами к одному сайту бот выдерживает паузу
(`request_delay_seconds`), а при ошибках «слишком много запросов» ждёт и повторяет.

### LolzMarket (официальный API)

| Что | Ограничение |
|---|---|
| Доступ к Market API | нужен токен с правом **market**, и у аккаунта должно быть **200 симпатий** на форуме **или платная подписка** на API |
| Лимит поиска (категории, в т.ч. Supercell) | 120 запросов в минуту (в старой части документации — 20 в минуту, т.е. 1 запрос в 3 с; бот по умолчанию держит паузу 3,5 с, так что укладывается в оба варианта) |
| Остальные GET-запросы | 300 в минуту |
| Превышение | ответ `429`, бот ждёт до сброса лимита и повторяет |
| Токен | имеет срок действия — бот предупредит в логе, если он истёк или скоро истечёт |
| Выдача | сайт кеширует результаты поиска, поэтому новое объявление может появиться с небольшой задержкой |
| Объём | бот смотрит первую страницу самых новых объявлений (около 40 штук) на каждое правило; если объявлений по вашим условиям появляется больше 40 за интервал — увеличьте `pages` |
| Адрес API | `api.lzt.market`; если он не отвечает, бот сам пробует запасной `prod-api.lzt.market` |

Домены форума `lolz.live` / `zelenka.guru` / `lolz.team` — зеркала: если одно не открывается
(в РФ `lolz.live` заблокирован), токен можно получить на другом.

### FunPay (публичная страница, без API)

| Что | Ограничение |
|---|---|
| API | **нет**; бот читает публичную страницу раздела «Аккаунты» (`funpay.com/lots/436/` — BS, `funpay.com/lots/149/` — CR) **без входа в ваш аккаунт**, поэтому ваш аккаунт FunPay ничем не рискует |
| Официальные лимиты | не опубликованы. При частых запросах FunPay отвечает `429`, может временно заблокировать IP (`403`), особенно IP серверов/VPS. Рекомендуется интервал **от 3–5 минут** |
| Пагинация | нет — весь раздел приходит одной страницей, бот видит все объявления сразу |
| Параметры аккаунта | только короткий текст объявления из списка (см. раздел 3), поэтому условия по кубкам/бравлерам на FunPay работают, только если продавец указал их в этом тексте |
| Цены | цена для покупателя (с комиссией FunPay), в валюте страницы. С российского IP это рубли; если FunPay покажет другую валюту (например, бот запущен за рубежом), бот предупредит, и условия по цене для FunPay перестанут срабатывать |
| Правила сайта | пользовательское соглашение FunPay запрещает автоматическое извлечение данных. Бот обращается к сайту редко и анонимно, но гарантировать, что FunPay не ограничит доступ, нельзя |
| Разделы аккаунтов | летом 2025 FunPay объявлял о закрытии разделов с передачей логина/пароля из-за новых законов РФ; в 2026 разделы 436 и 149 видны в поиске, но **откройте их на телефоне и убедитесь, что там есть объявления** |
| Вёрстка | если FunPay поменяет HTML или закроет раздел, бот после 3 неудачных проверок напишет об ошибке, а `py main.py --inspect-funpay` покажет, что именно он видит на странице |

### Telegram

- Не больше ~1 сообщения в секунду в один чат (в группу — 20 в минуту). Бот сам выдерживает паузы,
  а при ответе `429` ждёт, сколько скажет Telegram.
- Длина сообщения — до 4096 символов (длинные описания бот обрезает).
- Бот не может написать первым: обязательно нажмите **Start** в своём боте.
- Если Telegram временно недоступен, уведомления не теряются — бот дошлёт их при следующей проверке.
- С февраля 2026 Telegram в России замедляется/ограничивается. Если бот запущен на компьютере или
  сервере в РФ и сообщения не доходят, задайте `telegram.proxy` или запускайте бота на сервере за рубежом.

### Важно про сами аккаунты

Правила Supercell запрещают передачу и продажу аккаунтов: купленный аккаунт могут вернуть прежнему
владельцу или заблокировать. Смотрите на гарантию продавца (на LolzMarket — параметр `eg`).

## 7. Как держать бота включённым, когда компьютер выключен

Бот — обычная программа на Python, ей нужно постоянно работающее устройство с интернетом.
Варианты от самого надёжного:

1. **Недорогой VPS за пределами РФ** (Ubuntu 22.04/24.04, 1 ядро и 1 ГБ памяти более чем достаточно;
   например, Hetzner — порядка 4–6 € в месяц). Управлять можно с телефона по SSH (Termius, JuiceSSH),
   а интервал — прямо из Telegram командой `/interval`. Установите бота в `/opt/market-parser`
   как в разделе 2 (с `.venv`) и настройте автозапуск через systemd:

   ```ini
   # /etc/systemd/system/market-bot.service
   [Unit]
   Description=FunPay/Lolz monitor
   Wants=network-online.target
   After=network-online.target

   [Service]
   WorkingDirectory=/opt/market-parser
   ExecStart=/opt/market-parser/.venv/bin/python main.py --log-file bot.log
   Restart=always
   RestartSec=30

   [Install]
   WantedBy=multi-user.target
   ```

   ```bash
   sudo systemctl enable --now market-bot
   sudo systemctl status market-bot      # посмотреть состояние
   ```

   Учтите: IP дата-центров FunPay может блокировать чаще домашних. Если увидите постоянные `403`
   от FunPay — увеличьте интервал или используйте прокси (`monitor.proxy`).

2. **Бесплатные облака** (нужна банковская карта): Google Cloud Free Tier — одна маленькая
   виртуалка e2-micro в регионах США бесплатно; Oracle Cloud Always Free (бывают нехватка мощностей
   и отключение «простаивающих» машин). Настройка такая же, как у VPS.

3. **Android-телефон с Termux** (бесплатно, но телефон должен быть всегда включён и в сети):
   - установите Termux из F-Droid (версия из Google Play урезанная);
   - `pkg update && pkg install python git`, затем `pip install -r requirements.txt`;
   - `termux-wake-lock` и отключите оптимизацию батареи для Termux;
   - на Android 14+ включите в «Параметрах разработчика» пункт «Disable child process restrictions»
     (иначе система может убивать фоновые процессы).

Не подходят: PythonAnywhere free (нет постоянных задач, закрыт доступ к этим сайтам) и бесплатные
«засыпающие» веб-хостинги. Не запускайте бота одновременно в двух местах с одним токеном —
команды в Telegram перестанут работать (ошибка 409).

## 8. Если что-то не работает

- **`FunPay: HTTP 403`** — FunPay ограничил доступ по IP (слишком частые запросы или «плохой» IP хостинга).
  Увеличьте `interval_minutes` и `request_delay_seconds`, попробуйте прокси (`monitor.proxy`).
- **`FunPay: на странице нет ни одного объявления`** — раздел закрыт, пришла заглушка защиты от ботов
  или поменялась вёрстка. Откройте раздел в браузере; если объявления там есть — пришлите вывод
  `py main.py --inspect-funpay`, парсер нужно обновить.
- **`FunPay: вместо раздела lots/436 открылся другой`** — FunPay перенаправил на другой раздел
  (раздел закрыт или его номер поменялся). Поставьте `auto` в `funpay.categories` или впишите новый номер
  из ссылки `funpay.com/lots/<число>/`.
- **«FunPay показывает цены в USD/EUR»** — бот видит FunPay как иностранный посетитель. Запустите бота
  с российским IP (или через прокси `monitor.proxy`) либо уберите условия по цене для FunPay.
- **`LolzMarket: HTTP 401` / `HTTP 403`** — неверный или просроченный токен, у токена нет права `market`
  или у аккаунта нет доступа к Market API (200 симпатий или подписка).
- **`LolzMarket: HTTP 400 — …`** — в `lolz_params` неверный параметр; текст ошибки от сайта будет после тире.
- **Не приходят сообщения** — запустите `py main.py --test-telegram`: он скажет, что не так
  (неверный токен, неверный chat id, не нажат Start, нет связи с Telegram).
- **«этот токен уже опрашивает другая копия бота»** — бот запущен дважды (например, на ПК и на сервере).
- **Бот запустился, но ничего не проверяет** — он на паузе (`/pause` сохраняется после перезапуска): `/resume`.
- **Ошибка про `socksio`** — переустановите зависимости: `py -m pip install -r requirements.txt`.
- Подробный лог: `py main.py -v --log-file bot.log`.

```bash
py -m pip install -r requirements-dev.txt
py -m pytest
```

Структура: `parser_bot/funpay.py` (HTML FunPay), `parser_bot/lolz.py` (API LolzMarket),
`parser_bot/filters.py` (условия), `parser_bot/monitor.py` (цикл, решения об уведомлениях и команды),
