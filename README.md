# Побег — хоррор для Roblox

Кооперативный хоррор на 1+ игроков. Каждый раунд карта генерируется заново.

1. **Лобби.** Игроки ждут начала раунда (15 секунд).
2. **Подвал.** Тёмный лабиринт с мигающими лампами и надписями на стенах, которые видно только
   под фонарём. Нужно найти все ключи (по умолчанию 4) — тогда откроется дверь «ВЫХОД».
   Через 12 секунд после старта просыпается **Он**: видит в прямой видимости, слышит тех, кто
   рядом, и тех, кто бежит. Шагом от него не уйти, бегом — можно, но выносливость кончается.
3. **Лес.** За дверью — ночной лес: туман, мёртвые деревья, ели, брёвна, объявления «ПРОПАЛ».
   Нужно найти генератор (у него мигает фонарь) и запустить его, удерживая E 6 секунд.
   Генератор грохочет и приманивает **Тень**. После запуска загораются фонари вдоль тропы,
   открываются ворота, и можно уехать на машине.
   **Тень** появляется за спиной и подкрадывается, пока на неё никто не смотрит. Под взглядом
   она замирает, а если смотреть на неё 2,5 секунды — исчезает (и потом возвращается).
4. Кто не успел за 5 минут, того забирает тьма. За побег и найденные ключи начисляется
   статистика в таблице игроков (сохраняется в DataStore).

## Управление

| Действие | Клавиатура | Телефон / геймпад |
| --- | --- | --- |
| Фонарь | F | кнопка «Фонарь» / Y |
| Бег | Shift (удерживать) | кнопка «Бег» / L3 |
| Подобрать ключ, запустить генератор, сесть в машину | E | кнопка на экране |

Камера всегда от первого лица.

## Как запустить

Проект собирается через [Rojo](https://rojo.space). Нужные версии инструментов записаны в
`rokit.toml`.

1. Установите [Rokit](https://github.com/rojo-rbx/rokit) и выполните в папке проекта:
   ```sh
   rokit install
   ```
2. **Собрать файл места** и открыть его в Roblox Studio:
   ```sh
   rojo build default.project.json -o horror.rbxlx
   ```
   Откройте `horror.rbxlx` в Studio и нажмите Play.

   **Или синхронизировать с открытым местом** в Studio: установите плагин
   (`rojo plugin install`), запустите `rojo serve` и нажмите Connect в плагине Rojo.
   Карты строятся скриптами при запуске игры, поэтому в режиме редактирования мир пустой.
3. Для самой красивой картинки поставьте в Studio `Lighting → Technology = Future`
   (это свойство нельзя задать из скрипта).
4. Чтобы прогресс сохранялся, опубликуйте игру и включите
   `Game Settings → Security → Enable Studio Access to API Services`. Без этого игра тоже работает,
   просто статистика не сохраняется.

## Текстуры и звуки из Creator Store

Лес и подвал сделаны на встроенных материалах Roblox (терраин с травой и грязью, дерево,
бетон, металл), поэтому всё работает без загрузки картинок. Чтобы сделать страшнее, добавьте
текстуры из [Creator Store](https://create.roblox.com/store/decals) в `src/shared/Config.luau`:

1. Найдите декаль или картинку, например: `tree bark`, `dirty concrete wall`, `dirty floor tiles`,
   `chain link fence`, `missing poster`, `claw marks`, `blood splatter`.
2. Скопируйте число из ссылки: `create.roblox.com/store/asset/`**`1234567890`**`/...`
3. Вставьте его в `Config.Textures`:
   ```lua
   Config.Textures = {
       Bark = 1234567890, -- кора деревьев
       MazeWall = 0, -- 0 — встроенный материал
       ...
   }
   ```
   Подходят и декали, и картинки: сервер сам достаёт изображение из декали. Для коры, стен
   и пола лучше брать бесшовные (tileable) текстуры, для забора — сетку с прозрачным фоном.
   Размер плитки настраивается в `Config.TextureTiles`.

Звуки добавляются так же, в `Config.Sounds`, в виде `"rbxassetid://1234567890"`: фоновый гул
подвала, ночной лес, погоня, сердцебиение, дыхание монстра, скример, ключ, дверь, генератор,
щелчок фонаря. Пустая строка — звук выключен.

## Настройка

Все числа — в `src/shared/Config.luau`:

- `RoundTime`, `IntermissionTime`, `MonsterDelay`, `KeysToEscape` — длительность и цели раунда;
- `Maze` — размер лабиринта, доля ламп, лишних проходов (петель) и надписей;
- `Forest` — размер леса, число деревьев, брёвен, объявлений, время запуска генератора;
- `Monster` и `Shadow` — скорость, дальность зрения и слуха, поведение монстров;
- `WalkSpeed`, `SprintSpeed`, `Stamina*` — скорость и выносливость игрока;
- `Colors`, `WallWritings` — цвета и надписи на стенах.

## Структура

```
src/
  shared/Config.luau          настройки (сервер и клиент)
  server/
    Main.server.luau          точка входа
    GameLoop.luau             раунд: лобби → подвал → лес → машина
    Maze.luau                 генерация лабиринта и поиск путей (чистые данные)
    MapBuilder.luau           лобби и подвал из деталей
    ForestBuilder.luau        лес: терраин, тропа, деревья, генератор, ворота, машина
    Monster.luau              ИИ монстра подвала (зрение, слух, погоня по клеткам)
    Shadow.luau               ИИ Тени в лесу
    Scare.luau                поимка игрока и скример
    Textures.luau             текстуры из Creator Store
    PlayerData.luau           статистика и DataStore
    Build.luau                помощники для постройки
  client/
    Controls.client.luau      фонарь, бег, выносливость
    Atmosphere.client.luau    мигание ламп, туман по локациям, эффекты страха, звуки
    Hud.client.luau           интерфейс, сообщения, скример
tests/smoke.luau              проверка без Studio (Lune)
```

## Проверка кода

```sh
stylua --check src tests
selene src
rojo build default.project.json -o test.rbxlx
lune run tests/smoke test.rbxlx
```

Смоук-тест проверяет генерацию лабиринта, постройку подвала и леса для разных сидов,
то, что монстр ловит игрока рядом, а Тень подкрадывается, замирает под взглядом и исчезает.
